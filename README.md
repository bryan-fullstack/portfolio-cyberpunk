Esta é a minha interface profissional pessoal. Um projeto desenvolvido para unir uma estética imersiva (Cyber-inspired) com uma arquitetura de software moderna, limpa e totalmente responsiva.

**🔗 [Acessar o Portfólio Ao Vivo](https://portfolio-cyberpunk-tau.vercel.app/)**

---

## 🚀 Funcionalidades Principal

- **UI/UX Imersiva:** Design focado em contraste (Ciano/Fúcsia) com efeitos de *glassmorphism*.
- **Animações Fluídas:** Utilização de Framer Motion para transições de estado e interações de hover.
- **Responsividade Total:** Adaptado para dispositivos móveis, tablets e desktops (Mobile-First).
- **Sistema de Download:** Protocolo integrado para extração de currículo profissional em PDF.
- **Seção de Projetos:** Vitrine dinâmica para exibição de operações e tecnologias utilizadas.

---

## 🛠️ Stack Tecnológica

### Core
- **Framework:** [Next.js 14+](https://nextjs.org/) (App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)

### Bibliotecas & Ferramentas
- **Animações:** [Framer Motion](https://www.framer.com/motion/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Deploy:** [Vercel](https://vercel.com/)
- **Versionamento:** [Git & GitHub](https://github.com/)
